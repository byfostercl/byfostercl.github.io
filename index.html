PROYECTOS SELECCIONADOS

Trabajo realizado

Sistemas, automatizaciones y soluciones digitales desarrolladas a partir de procesos reales de operación, gestión y administración.

CASO PRINCIPAL

Thermomack

Sistema de Inteligencia Operacional

01

Plataforma multiusuario desarrollada para centralizar la trazabilidad de repuestos, operación en terreno y control de stock entre bodegas, contratos y técnicos. El sistema conecta la gestión operacional con Excel, Access y bases de datos para automatizar validaciones, reportabilidad y análisis para la toma de decisiones.

Aplicación Web Plataforma Multiusuario Conexión con Excel
ADMINISTRACIÓN DE CONTRATO · HRI / EPIROC

Reportabilidad Diaria

02

Sistema de recolección y reportabilidad desarrollado para centralizar la información diaria de flotas de equipos mineros. A partir de registros de terreno, horómetros, fallas, mantenimientos y tiempos de intervención, construye historiales por equipo y automatiza indicadores de disponibilidad, confiabilidad, MTBF, MTTR y comportamiento de fallas.

La estructura evolucionó y fue adaptada entre distintos contratos y empresas manteniendo una misma lógica operacional.

Dashboard Operaciones Automatización
BTS SERVICIOS

Actualización Digital

03

Conjunto de soluciones desarrolladas para modernizar procesos administrativos, técnicos y comerciales. El trabajo incluye automatización financiera y reportabilidad, digitalización del proceso documental de reparaciones para Anglo American y el rediseño de su presencia web e infraestructura de correo corporativo.

Automatización de Procesos Reportabilidad Técnica Ecosistema Digital
